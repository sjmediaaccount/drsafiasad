# 🌿 Dr. Safi Asad Homeopathic Clinic

Safe, natural, and side-effect-free homeopathic medical care website and patient/admin management portal.

## 🚀 Live Demo & Deployment

- **GitHub Repository**: [https://github.com/sjmediaaccount/drsafiasad](https://github.com/sjmediaaccount/drsafiasad)
- **Database Backend**: Supabase PostgreSQL (`jtnzjmcejnmeyyzeqcel`)
- **Hosting**: Vercel / GitHub Pages

---

## 🛠️ Features

- 🏥 **Patient Consultation Booking**: Online appointment booking system.
- 🔐 **Patient & Admin Authentication**: Secure login, registration, and session management.
- 📊 **Admin Dashboard**: Live statistics, appointment confirmation/cancellation, and patient records.
- ⚡ **Supabase Backend**: Real-time PostgreSQL database with automatic fallbacks.
- 🎨 **Modern Design**: Responsive CSS design with interactive UI components.

---

## 📁 Repository Files

- `index.html` — Main Clinic Website & Consultation Booking
- `admin.html` — Admin Login Portal
- `dashboard.html` — Patient Dashboard
- `admin-dashboard.html` — Admin Management Portal
- `admin-setup.html` — Admin Credential Setup
- `style.css` — Modern Responsive Styling
- `server.js` — Node.js Express Backend
- `api/index.js` — Vercel Serverless Function Entrypoint
- `supabase-schema.sql` — PostgreSQL Database Schema for Supabase
- `vercel.json` — Vercel Serverless & Static Routing Rules

---

## 📦 Local Setup

```bash
# Install dependencies
npm install

# Run locally
npm start
```

Visit: `http://localhost:8000`
